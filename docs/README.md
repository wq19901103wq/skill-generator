## 按场景选择文档

### 🚀 我是新手，想快速使用

1. 阅读 [../README.md](../README.md) - 了解项目
2. 按照"快速开始"生成第一个 Skill
3. 遇到问题查看 [FAQ.md](./FAQ.md)

### 🎨 我想创建自定义模板

1. 阅读 [TEMPLATE_GUIDE.md](./TEMPLATE_GUIDE.md)
2. 参考现有模板 `templates/personal_digital_twin/`
3. 测试并发布你的模板

### 🔧 我是开发者，想集成或扩展

1. 阅读 [API.md](./API.md) 了解编程接口
2. 查看 [../PROJECT_MAP.md](../PROJECT_MAP.md) 了解架构
3. 提交 PR 贡献代码

### ✏️ 我想手动编辑生成的 Skill

1. 阅读 [WIKI_GUIDE.md](./WIKI_GUIDE.md)
2. 直接编辑 `data/wiki/*.md` 文件
3. 重启 OpenClaw 生效
